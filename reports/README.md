the pre-refactor scripts, and every number in them was re-checked against a fresh run.

Notes on `strategy_honest_comparison.md`: the 15 June version was produced before the pivot fix and
had roughly a third of the trades; this rerun is on the corrected engine and reaches the same verdict.
V1's `enhanced` mode lists no trades because this harness passes `max_rr = 0` (meaning no cap for the
base mode), which the enhanced target check treats as a 0R ceiling. It is kept as is so the run stays
identical to the original.

Notes on `edge_corrected_findings.md`: it names functions from the original flat script layout, such as
`base.pivots()` and `run_edge_strategy._precompute_corners()`. `docs/methodology.md` section 10 maps them
to the package modules. Its 30m and 15m rows used M15 data for only two pairs, so it labels them
data-limited.

Reports that are **not** shipped: the confluence ranking and the monthly, scale-out, timeframe and risk
studies. They were all produced on 14 and 15 June, before the pivot fix, so their numbers carry the
look-ahead. Their code is still here under `src/fxresearch/analysis/` and reruns on the corrected
engine. Running any analysis script writes its report into this folder; only the files listed above
are meant to be committed.
